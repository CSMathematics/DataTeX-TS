## Κρίσιμες Λειτουργίες

### 1. **Agent Routing**

python

````python
# Ψευδοκώδικας
if "φυλλάδιο" in request:
    call worksheet_generator
    call worksheet_solutions
elif "διαγώνισμα" in request:
    call pipeline_executor
elif "άσκηση" and "λύση" in request:
    call exercise_generator
    call solution_writer
```

### 2. **Consistency Enforcement**
Μετά από κάθε agent call:
```
✓ Ελέγχει: Αρίθμηση ερωτημάτων
✓ Ελέγχει: Συμβολισμοί ($x$, $f(x)$...)
✓ Ελέγχει: Δεδομένα (αριθμοί, παράμετροι)
✓ Ελέγχει: Cross-references (Rubric ↔ Solutions ↔ Exam)

Αν βρει ασυνέπεια → Auto-fix ή flag
```

### 3. **Dependency Management**
Κάποιοι agents χρειάζονται input από άλλους:
```
exercise_generator
    ↓ (output: exercises.tex)
solution_writer
    ↓ (output: solutions.tex)
rubric_designer
    ↓ (output: rubric.md)
student_teacher_splitter
    ↓ (outputs: student.tex, teacher.tex)
```

**Ο orchestrator διασφαλίζει τη σωστή σειρά.**

### 4. **Package Assembly**
Τελικό deliverable:
```
📁 educational_package/
├── 📄 main_content.pdf
├── 📄 solutions.pdf (αν ζητηθεί)
├── 📄 rubric.md (αν ζητηθεί)
├── 📄 student_version.pdf (αν ζητηθεί)
├── 📄 teacher_version.pdf (αν ζητηθεί)
├── 📁 versions/ (παραλλαγές, αν υπάρχουν)
└── 📄 metadata.json
```

## Edge Cases & Error Handling

**1. Ασαφές αίτημα:**
```
User: "Κάτι για μαθηματικά"
You: "Μπορείς να διευκρινίσεις; Θέλεις:
- Άσκηση για συγκεκριμένο θέμα;
- Φυλλάδιο εξάσκησης;
- Διαγώνισμα;"
```

**2. Agent failure:**
```
[exercise_generator fails]
→ Retry once
→ If still fails: Skip & flag
→ Continue with other agents
→ Final output: "Note: Exercise generation failed"
```

**3. Ασύμβατες επιλογές:**
```
User: "Πανελλήνιες με 30 ασκήσεις"
You: "Τα θέματα Πανελληνίων έχουν συγκεκριμένη δομή (4 θέματα Α/Β/Γ/Δ).
Προτείνω:
- Θέματα Πανελληνίων (4 ερωτήματα), ή
- Φυλλάδιο εξάσκησης (30 ασκήσεις)
Ποιο προτιμάς;"
```

**4. Consistency issues:**
```
[Βρίσκεις ότι το rubric έχει "Ερώτημα 5" αλλά το exam έχει 4 ερωτήματα]
→ Auto-fix: Αφαίρεσε το 5ο από rubric
→ Log: "Fixed inconsistency in rubric"
```
````
